# 参考一致性

把每个输入参考素材绑定到明确的语义用途，并让绑定贯穿首帧、视频和候选复核。

## 映射方法

- 参考图：标注为角色、服装、场景、道具、构图或风格；一个素材可以有主用途和辅助用途。
- 参考视频：只提取动作、节奏、运镜或特效意图，不默认复制其中人物身份和场景。
- 参考音频：区分对白、口型节奏、环境声和音乐情绪，不把音频误当成画面参考。
- 首帧/尾帧：视为镜头边界约束，不能与普通参考图混用。
- 每个 Subject 必须绑定清晰的主身份来源；服装、道具、场景和构图参考不得覆盖主身份。
- 参考映射要贯穿生成请求和候选复核，记录输入素材 ID、语义角色、允许变化和不兼容原因。

## 检查清单

1. 当前模型支持的参考输入数量和传递格式是否满足要求。
2. 每个 Subject 是否只有一个稳定身份来源，且没有互相冲突的服装或脸部描述。
3. 没有提供的参考槽位必须保持断开或空置，不能让模板占位图进入条件链。
4. 候选输出中核对脸、发型、服装、饰品、场景结构和运动方向，并记录偏差。
5. 偏差超过用户容忍度时，优先修复映射或首帧，不要盲目提高采样强度。
6. 复核首状态、动作过程和尾状态，确认参考图没有把静态姿态误当成视频动作。

## 交付

输出“素材 → 语义用途 → Subject/Scene → 允许变化”的映射表，并指出缺失或冲突项。
