# 分镜提示词编译器

将自然语言导演意图转换为可复查、可跨镜头复用的镜头表示和模型请求。提示词编译不能借机重写剧情。

## 编译顺序

1. **事实**：场次、节拍、角色目标、对白、动作因果和用户锁定条件。
2. **主体**：稳定的 Subject/asset ID、数量、身份锚点、朝向、表情、服装、饰品和道具。
3. **动作**：起始状态、可观察动作链、反应/受力、动作幅度、结束状态；避免在一个短镜头塞入无关主动作。
4. **空间**：场景锚点、前中后景、角色相对位置、屏幕方向、视线、运动方向和空间基线。
5. **摄影**：景别、机位、焦段感、构图、焦点转移和运镜；摄影方案必须与走位和时长一致。
6. **节奏**：镜头时长、动作节拍、停顿、切点和转场意图；真实时间控制与文字提示分开记录。
7. **声音**：对白、口型节奏、环境声、动作声和音乐情绪；当前底座不支持时登记为后期项。
8. **约束**：身份漂移、服装/道具变化、肢体错误、闪烁、糊脸、文字水印、风格跑偏和不支持的参数。

## 规则

- 保留用户的剧情因果，不为了“画面好看”改变动作结果。
- 多角色用 Subject 1、Subject 2 等稳定编号，编号必须与参考素材映射一致。
- 涉及时间轴时使用明确的时间点或区间；没有真实时间轴节点时，不把时间戳伪装成节点控制。
- 生成前检查比例、分辨率、时长、首尾帧、参考数量、参考角色和工作流输入槽是否符合当前模型能力。
- provider 只接收被能力档案明确支持的字段；不支持的字段必须返回不兼容原因和替代方案。
- 同时输出“语义镜头 IR”“可直接提交提示词”“参考映射”“质量门”，便于失败后局部修复。
