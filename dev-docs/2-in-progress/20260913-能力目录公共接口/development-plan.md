# 能力目录公共接口

关联总任务 K03（能力管理页面）与 creative-ui 遗留技术债：图像工坊的"待接入能力"目前仅管理员可见（走管理员工作流分页接口），普通用户无法了解平台现有与即将提供的能力。本需求提供一个权限明确的公共只读目录接口，并让工坊页面统一从该接口取数。

## 范围

1. 后端新增 `GET /api/ai/capability/catalog?modelType=2`：任一登录用户可调用；聚合"已启用模型"与"待接入工作流"（未发布或已禁用）两类条目。
2. 返回字段最小化：id、name、description、source（MODEL/WORKFLOW）、enabled、default、pendingReason；不暴露 apiConfigId、code、绑定、哈希、路径等管理信息。
3. 前端图像工坊改为单次调用目录接口：已启用能力所有人可见；"待接入"区块所有人可见，"管理工作流"入口仅管理员显示。
4. 不改动生成链路，不把任何待接入能力标记为可用。

## 验收

- 普通用户与管理员调用目录接口均返回相同数据；响应中无管理敏感字段。
- 工坊页普通用户可见"待接入"区块（含 Klein 等三项），不再发出管理员接口请求。
- 单元测试覆盖条目映射与脱敏；生产构建通过；双视角浏览器/API 实测。
