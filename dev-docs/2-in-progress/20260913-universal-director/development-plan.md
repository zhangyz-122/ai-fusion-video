# 万能导演台 V1

## 目标

把视频创作收敛为一个统一入口：用户只描述内容、上传参考素材、选择输出参数并提交；底层使用管理员设定的默认视频底座，模型选择不再出现在主流程中。

## 本批范围

- 将 `/generate/video` 变为万能导演台入口。
- 保留现有参考图、首尾帧、参考视频、参考音频、时长、比例、分辨率、声音和候选数量能力。
- 锁定主流程模型为管理员配置的默认视频模型；未配置默认模型时使用当前启用列表的首个模型，并在界面标明底座名称。
- 保留 `/generate/videos` 作为管理员/高级用户查看单模型能力的入口，不在万能导演台里要求用户切换。
- 不在本批伪造二采、高清或声音生成能力；这些能力只有在已发布工作流绑定并通过在线验证后才能由底层执行。
- 导入一套平台原生漫剧 Skills：万能导演、角色/场景圣经、分镜提示词编译、参考一致性、视频 QC 修复。
- 已按外部研究结果校准内置 Skills：采用 Agent Skills 开放格式，吸收 Open Film Skills 的导演/分镜/动作方法和 Film Production Skills 的稳定 ID、资产覆盖、Shot IR、能力档案、重试与非破坏时间线原则；不复制第三方宿主专用运行时。
- 继续沿用现有 MCP 权限和 Agent 白名单，不自动接入未知外部 MCP 服务。

## 后续批次

- 为万能导演台建立独立的 `UNIVERSAL_DIRECTOR` WorkflowProfile，绑定经验证的综合 ComfyUI 图。
- 将二采、动作增强、SeedVR2 后处理接成同一工作流的条件分支，并让渲染器按输入开关裁剪未启用分支。
- 补充真实生产验收：5 秒、10 秒、多参考、音频、二采和高清各一条。
- 仅在直接平台工具无法覆盖时增加受控 RunningHub/ComfyUI MCP 适配器；默认关闭通用 Fetch/Filesystem 等高权限服务器。
- 将关联研究任务归档为可交接 Markdown 知识库，并维护来源索引、角色/表演资产、导演运行时、HTML/React/后端路径和综合平台旁支之间的关系。

## 验收标准

- `/generate/video` 首屏不出现模型切换控件。
- 提交请求仍携带实际底座模型 ID，现有任务历史和取消/轮询逻辑不变。
- 模型加载失败、无可用模型和能力校验仍明确报错，不静默降级。
- 前端生产构建通过。
