## 0. 原则

- 吸收 = 方法进我们的 ProductionRun / 资产 / 分镜 / 合成。

## 3. 后端优先吸收（相对融光已有）

融光已有且应继续用：VideoTask / Redis 队列 / Consumer / ProductionRun / 3 Takes / QC / Select / VideoComposeService / WorkflowProfile。

缺、应补：

1. **镜头状态机**：draft → has_bible → has_first_frame → ready → generating → qc → selected → composed。未 ready 禁止开 Run。
2. **圣经版本绑定**：镜头存 characterRevisionId / sceneRevisionId，禁止绑「最新」。
3. **Audio master timeline**：对白时长先于视频（ai-video-studio / InfiniteTalk）。
4. **导出契约**：成片 MP4 + 字幕 + 参数快照 + 可选剪映草稿（ArcReel/dramai）。
5. **成本账**：即使本地 GPU 也记耗时；云记金额（ArcReel）。
6. **Director IR**：剧本→ShotSpec，导演不写 Comfy 节点号（已有 Profile 层，缺编译器）。
