# 页面整改：把融光收成综合短剧制造平台

性质：B01 页面规格草案 + 整改意见。不是完成报告，不改代码。
依据：现网路由/侧栏/页面行数、总任务 IA、Codex「AI Drama OS」审计、ChatGPT Director Workbench v0.21→v1.0。

**策略更正（相对初稿）：** 融光只保留工程底座（认证、资产、队列、模型、生成、ProductionRun、Compose）。创作者看到的 UI / 页面 / 交互 / 信息架构全部新建，不在融光原顶栏上打补丁，也不把导演台 HTML 实验室搬进主站。

## 0. 一句话诊断

乱，不是因为缺功能，而是**三条产品同时活在一套导航里**：

1. 开源融光：仪表盘 + Agent 助手 + 独立生图/生视频工具
2. 项目制片：剧本 → 分镜 → ProductionRun → 三候选 → QC → 合成
3. 小说导演台：Book Compiler / Story Bible / Shot Graph / Production DAG（HTML 原型，未进主站）

后端已经能跑 `StoryboardItem → Run → 3 Takes → QC → Select → Compose`。页面却还在用「工具站」心智，入口互相抢，项目工作区撑不起一条短剧产线。

总任务里的「十二个一级入口」是**模块地图，不是顶栏**。若按十二项铺导航，会比现在更乱。

## 2. 产品脊柱（短剧制造平台只认这一条）

普通用户路径：

```
工作台
  → 打开/新建剧目
    → 策划简报（类型/画幅/风格/单镜时长/交付）
    → 剧本（分集分场，版本化）
    → 圣经（角色/场景/道具/声音，锁定版本）
    → 分镜（一场一镜，≤5s，锁首帧）
    → 生产（三候选 → QC → 选片）
    → 成片（时间轴/字幕/合成/交付包）
```

工坊是**带项目上下文的能力入口**，不是第二条产品：

- 图像工坊：角色设定、场景、分镜首帧
- 视频工坊：I2V / 首尾帧 / 对白口型（默认底座，不选模型）
- 声音工坊：对白时间线（首版可后做，入口先占位且标明未上线）

导演台（ChatGPT v1.0）不是新站点。它是项目里的 **Compiler**：小说/剧本 → Beat/Shot IR → 现有 StoryboardItem。生产 DAG 就是现有 ProductionRun，不要再做一套 HTML Worker。

默认生产契约（与 DramaClaw 质量门对齐，作为本平台 Profile，而不是第二个产品）：

- 一种风格（3D 漫剧 **或** 真人，项目级锁定）
- 一镜一动作，≤5s，锁首帧
- 禁止模型烧字/UI/证件
- 音频走已验证能力（H3 native AV 或 InfiniteTalk），未发布能力不出现在主路径
- 身份漂移只打回该镜，不整集重跑

## 3. 导航整改（模块 12 ≠ 顶栏 12）

### 3.1 顶栏只留 4 项

| 顶栏 | 路由 | 职责 |
|---|---|---|
| 工作台 | `/home`（现 `/dashboard` 重做） | 继续这部剧、失败任务、待 QC、快速生成 |
| 项目 | `/projects` | 剧目列表；进入后是制片工作区 |
| 工坊 | `/studio`（现 `/generate`） | 图像 / 视频 /（声音占位）；**记住当前项目** |
| 设置 | `/settings` | 成员、存储、密钥、能力（管理员） |

「资产」「生产中心」降为项目内 Tab + 工作台待办，不再占顶栏。全局资产检索放工作台或项目资产的「全部」视图。

### 3.2 项目工作区 Tab（这是「项目页面」的正解）

```
概览 | 剧本 | 圣经 | 分镜 | 生产 | 成片 | 资产 | 设置
```

- **概览**：一部剧的状态机（简报到交付），一个主按钮「继续下一件该做的事」，禁止四宫格统计墙
- **圣经**：角色/场景/道具/声音版本；镜头只绑版本，不绑「最新」
- **生产**：该项目的 Run 列表 + 点进即现有 Drawer（模型/Profile/三候选预览已有）
- **成片**：合成、字幕、交付包；首版复用 `VideoComposeService`

### 3.3 工坊侧栏（3 项，禁止 5 项）

```
图像工坊   /studio/image     目录 + 编辑器（query: modelId, assetId, shotId）
视频 / 导演台 /studio/video  默认 unified；?modelId= 仅管理员调试
声音工坊   /studio/audio     未上线则禁用并写原因，禁止假入口
```

删除或 301：

- `/generate/universal` → `/studio/video`
- `/generate/video` 与 `/generate/videos` 合并
- `/generate/image` 与 `/generate/images` 合并
- 旧 `/generate/*`、`/dashboard`、`/production`、`/assets` 保留 redirect 一到两个版本

### 3.4 能力管理不要进创作者顶栏

工作流、Profile、Runtime、哈希、绑定 → 设置 / 能力。创作者只看到「已发布且试运行通过」的能力名。未通过的标「待接入」，不可点进编辑器假装能用。

## 4. 页面级整改

### 4.1 工作台（替换仪表盘）

删：问候渐变、模型 3/3 配置卡、外部访问就绪、等权 StatCard。

留三块，主次分明：

1. **继续创作**（主）：最近剧目 + 该剧卡在哪一步（缺首帧 / 待 QC / 合成失败）
2. **待处理**（次）：现有 `/api/dashboard/activity` 已有进行中/待办，直接用
3. **能力入口**（辅）：图像、导演台、打开项目——各一个按钮，不要再做一套卡片市场

数据分析 `/dashboard/analytics` 移设置或砍掉。创作者不需要它在一级。

### 4.2 项目概览

从「资料夹」改成「制片看板」：

- 顶部：剧名、画幅、风格、目标单镜时长、当前集
- 中部：漏斗（剧本场次 → 有分镜 → 有首帧 → 已生产 → 已选片 → 已合成），数字可点
- 底部：本集下一步（唯一主按钮）

解析剧本、修数据、画风预设放到剧本 Tab / 设置，不要堆在概览。

### 4.3 分镜（核心工作区，必须拆文件）

先拆后改：

- `page.tsx` 只编排：选集场、视图切换、打开 Drawer
- 表/卡视图、参考面板、生产 Drawer 已经分子组件，页面不得再堆 1500 行状态

交互收口：

- 左：集/场树（已有 sidebar）
- 中：镜列表（表或卡，同一数据）
- 右：当前镜（对白、时长、首帧、引用角色版本、生成/看 Takes）
- 禁止第三套「生视频」跳到无项目上下文的 `/generate/video`

默认约束写在镜上：时长 ≤5s、必须首帧、风格继承项目简报。违反时禁用「生产」，文案写清缺什么。

### 4.4 导演台

`GenerationWorkbench` 的 `unified` 模式保留为工坊快捷入口，但：

- 提交必须能带 `projectId` + 可选 `storyboardItemId`
- 产物默认进当前项目资产，而不是只有全局生成历史
- 创作者不选模型；管理员调试用 `?modelId=` 或设置里的能力页
- 不要把 Director Workbench HTML（326k 的单文件）嵌进 Next

ChatGPT v1.0 可吸收进后端/Agent，而不是新页面：

| 原型概念 | 融光落点 |
|---|---|
| Story Bible | 项目圣经资产 + 稳定 entity_id |
| Chapter Compiler / IR | 剧本解析的下一阶段，输出 StoryboardItem |
| Incremental Recompile | 场/镜指纹，改文案不重跑视频 |
| WAITING_WORKFLOW / WAITING_ASSET | 现有 Run 状态扩展，已有「未配置参考图」类失败应对齐到此 |
| Production Worker | 现有 Consumer + Reaper，禁止再起 Python Worker |
| Workflow Profile | 已有 Profile；继续修绑定，不平行注册 |

### 4.5 生产页

全局 `/production` 降级为工作台「全部任务」或项目 Tab。Drawer 已有模型/Profile/预览，不要再做第三套选片 UI。

### 4.6 设置

拆成创作者 / 管理员：

- 所有人：个人、默认项目、通知
- 管理员：用户、存储、AI 模型、工作流发布、Agent/MCP

`ai-models/page.tsx`（974 行）按「模型列表 / 工作流版本 / Profile」拆页。

## 5. 明确不要做

1. 不要把十二模块做成十二个顶栏
2. 不要把 Director Workbench HTML / Production Worker 搬进仓库当正式 UI
3. 不要再加 `/generate/xxx` 新入口；先合并旧的
4. 不要在分镜之外再做一套「漫剧工作台」
5. 不要把未发布能力（InfiniteTalk 无音频试跑、二采、SeedVR2）画成可点按钮
6. 不要为了页面好看再给卡片加彩虹光晕、多层毛玻璃
7. 不要未写 B01 规格就继续补局部入口（这正是今天乱的原因）
8. 不要把 DramaClaw / 一键包 Comfy 当融光 Runtime；融光只认已登记且试跑通过的 Profile
