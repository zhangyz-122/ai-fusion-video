# 完成总结：创作 UI 第一批（20260913-creative-ui）

## 最终范围

- 新增 `/generate` 创作工作台（图像工坊 / 视频创作 / 项目中心三入口）与 `/generate/images` 图像工坊。
- 顶部导航新增"创作工作台"入口；旧生图 `/generate/image`、生视频路由保留并支持 `?modelId=` 指定模型启动。
- 图像工坊从真实模型 API 读取已启用图片模型；管理员额外可见工作流分页 API 的待接入项（Klein 3 项），普通用户不请求管理员接口。
- 不重做全部编辑器，不新增后台运行链，复用旧生成器与记录。

## 关键实现

- 工作台/工坊页面按设计系统实现，提供加载、错误、空状态；页面明示"配置启用不代表已完成出图测试"。
- 指定模型启动：工坊卡片链接带 `modelId`，编辑器选中对应模型；模型 14（文戏生图）无附件输入，模型 15（参考图生图）支持参考图。
- 权限隔离：普通用户整页 API 清单不含 `/api/ai/comfyui/workflow/*`。

- 生产构建（含 TypeScript）通过；Docker 前端镜像重建并上线。
- 桌面端浏览器验证：工作台、工坊、Klein 待接入项（管理员）、指定模型进入编辑器、既有创作记录读取。
- 普通用户（uitest，仅 user 角色）：三页面正常，仅见 2 个启用模型与本人记录；未请求管理员工作流接口。
