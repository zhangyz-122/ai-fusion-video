# 技术债务

## 遗留

1. **原文保存即重置（后端语义限制）**：`PUT /api/script/{id}/source` 的 `replaceSourceAndReset` 把"保存原文"与"重置剧集/场次"绑定为一个事务语义。原文页目前靠前端确认弹窗兜底；若后续要支持"不影响已有剧集地微调原文"，需要后端提供仅更新 `raw_content` 的接口并重新定义两侧数据的一致性语义。
2. **分集校验的读取放大**：转换 `onComplete` 校验会对所有分集各发一次场次列表请求（与概览页既有模式一致）。分集数接近上限（50）时为 50 次请求，可考虑后端提供聚合统计接口。
3. **大文本编辑体验**：编辑弹窗以 textarea 承载完整原文，数百万字时输入会有卡顿；当前与旧弹窗行为一致，未做虚拟化。
4. **浏览器验收欠账**：本次仅完成类型检查与生产构建验证，未在运行环境中走通"导入原文 → 转剧本 → 剧本页出现剧集"的端到端交互，待下次部署后补冒烟。
